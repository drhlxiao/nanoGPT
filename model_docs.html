nanoGPT: model.py

Full definition of a GPT language model in a single file (≈330 lines of PyTorch).

References:

  • OpenAI GPT-2 TensorFlow implementation: openai/gpt-2 model.py
  • Hugging Face Transformers GPT-2: modeling_gpt2.py

1. Overview

model.py contains a decoder-only Transformer (the GPT family) that models the probability of the next token given all previous tokens:

P(x1, …, xT) = ∏t=1T P(xt | x1, …, xt−1)

The file provides:

Class / functionRole
GPTConfigDataclass of hyperparameters (depth, width, heads, vocab, context length, dropout, bias).
GPTThe full language model: embeddings, stack of Transformer blocks, output head, loss, generation, GPT-2 weight loading, optimizer setup, MFU estimate.
BlockOne Transformer layer (pre-LayerNorm attention + MLP with residual connections).
CausalSelfAttentionMulti-head masked (causal) self-attention. Uses Flash Attention when available.
MLPPosition-wise feed-forward network with a 4× expansion and GELU activation.
LayerNormLayerNorm with an optional bias (nn.LayerNorm could not disable its bias in the PyTorch versions this targets).

2. Model architecture

The architecture follows GPT-2: a decoder-only, pre-LayerNorm Transformer with learned absolute position embeddings, GELU MLPs, and an output head tied to the input token embedding.

2.3 Components

LayerNorm

Wraps F.layer_norm with an optional bias, because nn.LayerNorm could not disable its bias in the PyTorch versions this code targets. Normalizes each token's C-dimensional vector to zero mean and unit variance, then applies learned scale (weight, init 1) and optional shift (bias, init 0). ε = 1e-5.

CausalSelfAttention

  • c_attn: a single Linear(C, 3C) that produces Q, K and V for all heads at once.
  • c_proj: output projection Linear(C, C) that mixes the concatenated heads.
  • attn_dropout / resid_dropout: dropout on attention weights and on the projected output.
  • Flash path: if F.scaled_dot_product_attention exists (PyTorch ≥ 2.0), it is used with is_causal=True. Otherwise a manual implementation with an explicit lower-triangular mask buffer bias is used (and a warning is printed).

MLP

Linear(C → 4C) → GELU → Linear(4C → C) → dropout. Applied independently to each position; it is where most of the per-token “knowledge” parameters live.

Block

Pre-LayerNorm residual block:

x = x + attn(ln_1(x))
x = x + mlp(ln_2(x))

Normalization is applied before each sub-layer, and the residual path is kept clean, which makes deep stacks easier to train than the post-LN original Transformer.

GPT

3. Key algorithms

3.1 Causal self-attention

For each head, with queries Q, keys K and values V of size dk = C/H:

Attention(Q, K, V) = softmax( QKᵀ / √dk + M ) · V

where M is a causal mask with 0 on and below the diagonal and −∞ above it, so position t can only attend to positions ≤ t (no peeking at future tokens).

Steps in forward:

  1. Joint projection: c_attn(x) gives (B, T, 3C); split into Q, K, V of (B, T, C) each.
  2. Head split: reshape to (B, T, H, C/H) and transpose to (B, H, T, C/H). All heads are then computed in parallel as a batch dimension.
  3. Scores & mask & softmax (manual path): 
    att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(k.size(-1)))   # (B,H,T,T)
att = att.masked_fill(self.bias[:,:,:T,:T] == 0, float('-inf'))
att = F.softmax(att, dim=-1)
att = self.attn_dropout(att)
y   = att @ v                                                          # (B,H,T,hs)
  4. Flash path: a single fused call performs steps 3 (scale, mask, softmax, matmul) in one kernel without materializing the T×T matrix: 
    y = F.scaled_dot_product_attention(q, k, v, attn_mask=None,
        dropout_p=self.dropout if self.training else 0, is_causal=True)
  5. Head merge: transpose back to (B, T, H, hs) and reshape to (B, T, C).
  6. Output projection: c_proj, then resid_dropout.
Why the 1/√dk scaling? Dot products of random vectors grow with dimension; without scaling the softmax saturates and gradients vanish. Dividing by √dk keeps the variance of the scores ≈ 1.

3.2 Forward pass & loss

def forward(self, idx, targets=None):
    pos = torch.arange(0, t)                       # (t,)
    tok_emb = self.transformer.wte(idx)            # (b, t, C)
    pos_emb = self.transformer.wpe(pos)            # (t, C)
    x = self.transformer.drop(tok_emb + pos_emb)
    for block in self.transformer.h:
        x = block(x)
    x = self.transformer.ln_f(x)

    if targets is not None:
        logits = self.lm_head(x)                   # (b, t, V)
        loss = F.cross_entropy(logits.view(-1, V), targets.view(-1), ignore_index=-1)
    else:
        logits = self.lm_head(x[:, [-1], :])       # (b, 1, V): last position only
        loss = None
    return logits, loss
  • Loss is the average token-level negative log-likelihood (cross-entropy) of the next token:
    L = −(1/N) Σt log Pθ(xt+1 | x≤t)
    Targets equal to -1 are ignored, which lets callers mask out padding or invalid positions.
  • Inference shortcut: when no targets are given, only the final position is projected to the vocabulary, saving a factor of T in the largest matrix multiply of the model.
  • Positions are absolute: wpe is looked up by index 0..t-1, so t ≤ block_size is asserted.

3.3 Weight tying

The input embedding and the output projection share one matrix:

self.transformer.wte.weight = self.lm_head.weight

This saves 38.6M parameters (≈31% of the model) and ties the “meaning” of each token in input and output space. Because parameters() de-duplicates shared tensors, the total count above (124.48M) already includes it once.

3.4 Initialization

  • All Linear and Embedding weights: N(0, 0.02²); Linear biases: 0.
  • Residual projections (c_proj.weight in both attention and MLP) are scaled down to N(0, (0.02/√(2L))²). Each block adds two such outputs to the residual stream, so this keeps the variance of the residual stream from growing with depth (GPT-2 paper, §2.3).

3.6 Autoregressive generation

generate(idx, max_new_tokens, temperature, top_k) repeatedly samples one token and appends it:

  1. Context cropping: if the sequence exceeds block_size, keep only the last block_size tokens.
  2. Forward: get logits for the next position: logits[:, -1, :].
  3. Temperature: divide logits by τ. τ < 1 sharpens the distribution, τ > 1 flattens it.
  4. Top-k filtering (optional): set every logit below the k-th largest to −∞, so only the k most likely tokens remain.
  5. Softmax + multinomial sampling: probs = softmax(logits), then torch.multinomial(probs, 1).
  6. Append the sampled token and repeat.

The method is decorated with @torch.no_grad(); call model.eval() beforehand so dropout is disabled.

p(xt+1 = i) = exp(zi / τ) / Σj ∈ top-k exp(zj / τ)

3.7 Loading GPT-2 weights (from_pretrained)

Builds a nanoGPT model with the matching GPT-2 size, then copies tensors from Hugging Face's GPT2LMHeadModel:

gpt21212768124M
gpt2-medium24161024350M

Key details:

  • Hugging Face's GPT-2 uses Conv1D, which stores weights transposed relative to nn.Linear. The four matmul weights (attn.c_attn, attn.c_proj, mlp.c_fc, mlp.c_proj) are therefore transposed on copy: sd[k].copy_(sd_hf[k].t()).
  • The causal-mask buffers (attn.bias, attn.masked_bias) are skipped since they are not parameters.
  • vocab_size is forced to 50257, block_size to 1024, bias to True; only dropout may be overridden.

3.8 Cropping the block size (crop_block_size)

Reduces the context length of a trained model (e.g. 1024 → 256) by slicing the position embedding table and each attention mask. Since position embeddings are learned per index, the first 256 rows are still valid. Only valid downward: assert block_size <= config.block_size.

3.9 MFU estimation (estimate_mfu)

Model FLOPs Utilization estimates how efficiently hardware is used, following the PaLM paper (Appendix B):

FLOPs/token ≈ 6N + 12·L·H·Q·T     MFU = (FLOPs/token · T · fwdbwd_per_iter / dt) / 312 TFLOPS

fwdbwd_per_iter is the number of sequences processed per optimizer step and dt is the wall-clock seconds per step, so T · fwdbwd_per_iter / dt is the token throughput.

  • N: number of non-embedding parameters; 6N covers forward + backward matmuls.
  • 12·L·H·Q·T: attention score and value computations (L layers, H heads, Q = head size, T = context).
  • 312e12: A100 bfloat16 peak FLOPS, used as the reference denominator.

5. Notes

Known caveats in the code
  • The manual attention path is only used when PyTorch < 2.0 (no scaled_dot_product_attention); it registers the bias mask buffer only in that case. crop_block_size guards with hasattr(block.attn, 'bias') for this reason.
  • In generate, top-k filtering uses logits < v[:, [-1]], which keeps ties at the k-th value; more than k tokens may survive when logits are equal.
  • estimate_mfu is an approximation: the PaLM formula counts attention FLOPs over the full T×T score matrix and ignores the causal mask's ~2× sparsity, so it slightly overstates the work.
